# 界面截图

这个目录用来存放 README / 简历里引用的界面截图。仓库里只保留本说明文件，截图本身请自行补充。

## 建议补充的 4 张

按下面的顺序截图，覆盖「前台 + 后台 + 文档」三块能力，信息密度最合适：

| 文件名 | 页面 | 建议展示内容 |
| --- | --- | --- |
| `01-gallery.png` | 前台宠物列表 | 筛选栏 + 至少 6 张宠物卡片（体现网格布局与状态标签） |
| `02-apply.png` | 宠物详情弹窗 | 结构化宠物信息 + 领养申请表单 |
| `03-dashboard.png` | 后台数据看板 | 5 个统计卡 + 4 张 ECharts 图表 |
| `04-review.png` | 后台领养审核 | 申请表格 + 审核弹窗 |

可选：`05-swagger.png`（http://localhost:3000/api-docs）。

## 怎么截

1. 起服务：

   ```bash
   npm run db:reset && npm run dev      # 后端 :3000
   cd web && npm run dev                # 前端 :5173
   ```

2. 浏览器窗口拉到 **1440 × 900** 左右，页面内容撑满，避免大片留白。
3. 后台页面需要先用 `admin / admin123` 登录。
4. 截图后按上表重命名，放进本目录，然后在 `README.md` 的「截图」小节里引用，例如：

   ```markdown
   ### 宠物浏览

   ![宠物列表](docs/screenshots/01-gallery.png)
   ```

## 小提示

- 用系统截图工具（Windows `Win + Shift + S`）即可，不必装额外软件。
- 一张图只讲一件事，别把整个浏览器（含书签栏、其它标签页）截进去。
- 图片宽度控制在 1600px 以内，PNG 比 JPG 更适合界面截图（文字边缘更干净）。
