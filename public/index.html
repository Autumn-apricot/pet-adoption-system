接口一览

方法路径说明
POST/api/auth/register注册
POST/api/auth/login登录，返回 JWT
GET/api/pets宠物列表（分页 / 搜索 / 筛选）
GET/api/pets/:id宠物详情
POST/api/adoptions提交领养申请
GET/api/adoptions/mine我的申请
PUT/api/adoptions/:id/review审核申请（管理员）
DEL/api/pets/:id删除宠物（管理员）

完整清单请见 Swagger 文档。 默认管理员账号：admin / admin123（执行 npm run db:init 时创建）。

认证方式

除注册、登录和宠物读接口外，其余接口都需要在请求头带上 JWT：

Authorization: Bearer <token>

统一响应格式 { code, message, data }，HTTP 状态码与 code 一致。
